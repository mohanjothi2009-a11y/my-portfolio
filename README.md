## 🚀 Live Deployment via GitHub Pages (Free Hosting)

To host this website live on the web for free:

1. Create a repository on GitHub named `mohan-portfolio` (or `<your-username>.github.io`).
2. Push or upload these files to the repository.
3. In your GitHub repository:
   - Navigate to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Select branch **`main`** and folder **`/ (root)`**.
   - Click **Save**.
4. Your website will be live at `https://<your-username>.github.io/mohan-portfolio/` in less than 2 minutes!
